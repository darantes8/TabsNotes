Política de Privacidade — TabNotes

O TabNotes é uma extensão para Google Chrome que permite criar e organizar notas flutuantes diretamente nas abas do navegador.

Dados armazenados

O TabNotes armazena somente as informações necessárias para sua funcionalidade principal, incluindo o conteúdo das notas criadas pelo próprio usuário e preferências como título, cor, posição, tamanho, fonte, alinhamento e estado de minimização.

Esses dados são armazenados localmente no navegador utilizando as APIs de armazenamento do Google Chrome.

O TabNotes não coleta nomes, endereços de e-mail, informações financeiras, informações de saúde, credenciais, localização, histórico de navegação ou conteúdo das páginas visitadas.

Transmissão de dados

O TabNotes não envia o conteúdo das notas ou outras informações do usuário para servidores externos.

Nenhum dado é vendido, compartilhado ou transferido para terceiros.

Publicidade e rastreamento

O TabNotes não utiliza dados para publicidade, rastreamento, criação de perfis ou análise de comportamento.

Armazenamento

Em abas normais, as notas são armazenadas localmente pelo Google Chrome. Em navegação anônima, são utilizados dados temporários de sessão.

Exclusão dos dados

O usuário pode excluir suas notas diretamente pela extensão. Os dados da extensão também podem ser removidos ao desinstalar o TabNotes.

Contato

Para dúvidas relacionadas à privacidade, utilize o endereço de suporte informado na página do TabNotes na Chrome Web Store.
